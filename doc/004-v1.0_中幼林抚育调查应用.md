## 3. 设计方案（逻辑+口径依据，引用证据文件）

- 使用 Flask、SQLite、openpyxl 和原生 JavaScript，沿用 supervision 的移动优先交互与绿色视觉。
- 上传时把第一个 sheet 作为基础数据，按合并表头定位字段；项目名保留原始文件名。解析器依据表头文本和样地表公式生成配置，不按固定列号写死基础数据。
- 小班筛选采用标段、乡镇、村委会级联下拉，小班号模糊搜索，显示匹配数并可重置。
- 调查页只展示当前小班树种组成包含的树种，保留固定胸径、树高、数字株数、采伐株数、单株材积与径阶蓄积；输入后即时重算并自动保存。
- 材积以样地表公式为当前项目的直接依据；平均胸径采用株数加权平方平均，每公顷株数/蓄积沿用样地表 `×15` 口径。树高和株数必须为非负数，株数为整数。
- 图片使用 Canvas 等比压缩，最长边 1440px、JPEG 质量 0.8，不放大小图；添加时间/坐标水印并上传压缩后的文件。
- 卫星跟踪使用浏览器 Geolocation 与 Leaflet 卫星底图，保存 WGS-84 轨迹点，本地缓存防止刷新丢失，支持轨迹距离和 GPX 导出。定位与卫星瓦片需要设备和网络支持。

## 4. 代码修改（文件+行号+要点，不写全 diff）

- `workbook.py`：按合并表头读取第一个 sheet，解析树种组成，提取样地表胸径和公式参数。
- `calculations.py`：实现 Excel 式半步进位、单株/径积材积、采伐蓄积、平均胸径、每公顷换算与轨迹距离。
- `app.py`：实现项目上传、小班详情、调查自动保存、照片存储、轨迹保存及 GPX API。
- `static/app.js`、`static/style.css`、`templates/index.html`：实现项目列表、级联筛选、树种动态调查网格、数字株数控件、照片压缩和 Leaflet 卫星轨迹。
- `main.py`、`tools/checks/`：提供确定性批量校验输出和可重复闸门。
