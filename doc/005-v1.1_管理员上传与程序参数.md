## 2. 验证结果（改前数据对比/报错现场）

- `hqz-supervision` 目录名末尾含 U+200C，直接 `cd` 失败，需通配符定位。
- 参考项目的部署链路：`deploy.sh`（rsync → appspec → 首页 apps 表登记 → 重启 `gateway.service`）+ `deploy/supervision.appspec`；`create_app(prefix='')` 由 gateway 以 `create_app(prefix=spec['prefix'])` 调用，DispatcherMiddleware 剥前缀并设 SCRIPT_NAME，**路由不挂 url_prefix**。
- 参考项目的 App 链路：Capacitor 6 远程 URL 壳（`server.url`）+ `.github/workflows/android-build.yml`（push 出 debug APK）、`release.yml`（v* tag 出签名包并发布 Releases）。
- 本项目 v1.0 无用户表、无鉴权、上传在 `POST /api/projects` 且任何访问者可调用；`workbook.py` 只解析第一个 sheet 与样地表。
- 参考参数表为 `key|value|类型|默认值|说明|示例` 六列，多值半角 `;`，未知 key 报错。

## 3. 设计方案（逻辑+口径依据，引用证据文件）

- **部署**：新增 `deploy/exp-survey.appspec`（`prefix: /exp-survey`、`factory: app:create_app`、`static_url_path: /exp-survey/static`）；`deploy.sh` 只推运行必需文件，数据目录 `instance/` 不覆盖；gateway 剥前缀后 `prefix` 仅用于页面 base 与 cookie 限定。补 `_EmptyPathFix`：剥前缀后空 PATH_INFO 归一为 `/`，避免 werkzeug 308 用明文 scheme 拼 Location 触发 WebView `ERR_CLEARTEXT_NOT_PERMITTED`（supervision 实测坑）。
- **App**：Capacitor 6 + JDK 17 + Node 22；`server.url=https://forest.bibook.top/exp-survey/`，网页更新无需重装；Manifest 补 CAMERA / ACCESS_FINE_LOCATION / READ_MEDIA_IMAGES（拍照、轨迹、相册）。
- **权限**：`users(role admin|user, is_owner 超管)`；`@admin_required` 守住所有 `/admin/api/*`；覆盖时服务端校验 `uploader == 当前用户 || is_owner`，并要求请求体 `confirm` 等于当前项目文件名——前端确认只是提示，**服务端必须再校验一次**。首次启动按 `EXP_ADMIN_USER/EXP_ADMIN_PASSWORD` 播种超管，缺省 admin/admin123 并在日志告警。
- **上传迁移**：`POST /api/projects` 保留但返回 403，指向 `/admin/`；App 首页移除上传区，admin 才显示「管理」入口与提示条。
- **覆盖策略**：按小班号（第一个 sheet 的 `number` 字段）对齐；命中行就地 UPDATE（`subcompartment.id` 不变 → 照片外键、调查数据、轨迹全保住）；新行追加；旧表独有行**不删除**；写库前把旧 project + 全部小班快照落到 `instance/backups/`。
- **程序参数**：sheet 名 `程序参数`（兼容 `参数`），六列表头，6 个 key：
  | key | 取值 | 默认 | 作用 |
  |---|---|---|---|
  | 功能 | 拍照;视频;轨迹;打卡 | 拍照;轨迹 | 不含「轨迹」即默认不显示轨迹 |
  | 压缩最长边 | 320–4096 | 1440 | 仅影响新拍照片 |
  | 压缩质量 | 0.3–1.0 | 0.8 | JPEG 质量 |
  | 不显示列 | 基础数据表头 | 空 | 小班列表隐藏列 |
  | 水印内容 | 时间;坐标;小班 | 全部 | 去掉「坐标」即不写定位 |
  | 轨迹采样间隔 | 1–60 秒 | 5 | watchPosition 回调按时间窗节流 |
- **零改动兼容**：无参数 sheet 时全部取默认值，行为与 v1.0 一致；参数 sheet 不得占据第一个 sheet（否则明确报错）。

## 4. 代码修改（文件+行号+要点，不写全 diff）

- `param_parser.py`（新增）：`parse_program_params` / `public_params` / `default_params`；未知 key、重复 key、全角分隔符、非法取值、越界数值、隐藏列不存在 → `ParamError` 带 Excel 行号。
- `auth.py`（新增）：`ensure_users` 播种、`login_required` / `admin_required`、`can_overwrite`、`verify_password`。
- `app.py`（重写）：`create_app(prefix="", test_config=None)`；projects 增加 `uploader/params_json/is_active` 与老库 `ALTER TABLE` 迁移；新增 `/api/me|login|logout|password`、`/admin/` 页面与 `/admin/api/projects|update|source|users`；调查/照片/轨迹接口全部 `login_required`；HTML 响应 `no-cache`。
- `workbook.py`：`parse_workbook` 返回 `params`；第一个 sheet 是参数表时直接报错；`parse_base_rows` 一并返回表头名供参数校验。
- `templates/index.html`：移除上传区，加登录遮罩、用户区、管理入口、参数提示。
- `templates/admin.html` + `static/admin.js`（新增）：上传、项目表、预检 → 输入文件名确认 → 覆盖、源文件下载、用户与重置密码。
- `static/app.js`：`BASE` 前缀（`url()`）、登录态 bootstrap、动态列表列、按参数隐藏照片/轨迹卡片、压缩参数与水印行、轨迹采样节流。
- `static/style.css`：登录页、管理卡片、模态、预览网格、顶栏文字按钮。
- `package.json` `capacitor.config.json` `www/` `android/` `.github/workflows/*`：App 壳与 CI。
- `deploy/exp-survey.appspec`、`deploy.sh`：gateway 部署。
