# 006 - v1.2 接入森林门户统一账号

## 1. 需求背景（用户原话）

> 登录使用 https://forest.bibook.top/forest-data 用户体系；参考 /Users/sux/Desktop/hqz-supervision 的踩过的坑，同时 app 确认使用 https://…

确认口径（2026-11-23 三问三答）：

1. App 壳保持 `https://forest.bibook.top/exp-survey/`，本次只复核 https 能打开、登录回跳不丢前缀。
2. 普通用户只要有 forest-data 账号即可使用，**不**按 `user_app_grants` 拦（该表里 exp-survey 当前 0 条授权）。
3. 覆盖权限：forest-data 的 `is_admin=1` 等价于原「超级管理员」，可覆盖任何人；普通用户只能覆盖自己上传的项目。

| 项 | 改前 |
|---|---|

**上线后实机反馈（10:06）**：App 内登录报「不是有效 JSON」。复现结论两条，都不是账号体系本身的问题：

1. Capacitor WebView 缓存了 v1.1 的 `app.js`（无版本号），旧页面仍 `POST /api/login`，该路由已删 → 404 HTML → `response.json()` 抛 `Unexpected token '<' … is not valid JSON`。
2. 普通用户登录后门户 `_login_redirect` 会做 `check_app_access(user_id, 'exp-survey')`，而授权表里 0 条 → 被弹回 `/forest/`，等于「登录成功但进不了应用」。

隐患（不是本次引入，是 hqz-survey 已在 2026-08-24 踩过的）：`Path=/exp-survey` 的 session cookie 与门户 `Path=/` 同名，浏览器「最长路径优先」→ 门户登出后本应用仍认旧 `user_id`，换账号会串成前一个人。

## 3. 设计方案（逻辑+口径依据，引用证据文件）

- **身份来源**：只读 `session["user_id"]`（forest-data `auth.py` 登录成功时写入），其余字段现查 `forest_web.db.users`：
  `is_active=1`、`expires_at` 不早于今天、`is_admin` 决定管理权限。
  同域共享 cookie 的前提是 `SECRET_KEY` 与 forest-data 完全一致 → 读 `apps/forest-data/web/.secret_key`。
- **三条只读原则**（写进 `auth.py` 文件头）：
  1. 本应用不写 session；登出只在门户 `/forest/logout` 做；
  2. `SESSION_COOKIE_PATH="/"`，并**删除** `APPLICATION_ROOT`（它就是 cookie 前缀的来源）；
  3. 所有跳转用 `request.script_root`，不硬编码 `/`（网关剥前缀后硬编码会跳回 gateway 首页）。
- **残留清理**：`after_request` 对每个响应 `delete_cookie("session", path="/exp-survey")`，清 v1.1 及以前留下的旧前缀 cookie（只删不写）。
- **接口契约**：`/api/me` 返回 `login_url` / `logout_url`；401 时 JSON 也带 `login_url`，前端直接跳转，不再收密码。
- **App 壳**：`server.url` 保持 `https://forest.bibook.top/exp-survey/`，`cleartext=false`，`allowNavigation` 含 `forest.bibook.top`（登录页同域，WebView 内可完成跳转）。

关键断言：

- 未登录 `/` → `302 /forest/login?next=/exp-survey/`（带 `SCRIPT_NAME` 模拟网关）；
- `SESSION_COOKIE_PATH == "/"`，响应里 `Path=/exp-survey` 的 cookie 只允许是 1970 过期删除指令；
- `is_active=0` / `expires_at=2020-01-01` / 不存在的 user_id → 一律 401；
- 普通用户 `/admin/api/projects` → 403（JSON，不是 302 HTML），`/api/projects` → 200；
- 另一个 admin 覆盖他人项目 → 200；
- 旧接口 `/api/login`、`/admin/api/users` → **410 + JSON + login_url**（不再是 404 HTML）；
- 首页 HTML 只引用带版本的 `app.js?v=v1.2.1`，且该 URL 返回 `Cache-Control: public, max-age=604800`。
