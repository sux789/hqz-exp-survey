# 012 - v1.6 迭代记录_调查树种固定（不按组成拆分）

## 1. 需求背景（用户原话）

> 调查页面显示的树种，目前是树种组成拆分，但是有特殊情况，不按树种拆分，写在程序参数里面，调查写这 4 种，格式符合非技术人员填写：云南松  油杉  其他阔叶  栎类

现状：调查页每一列 = 「树种组成」里拆出来的一组「系数+名称」（如 `9云南松1其他阔叶` → 云南松、其他阔叶两列）。
现场的特殊小班组成写不准（混交、目测折算），外业实际是按四大类点数，希望**调查页固定显示 4 个树种**，
且这个口径写在程序参数里，不改数据、不改代码就能换。

## 2. 验证结果（改前）

- 树种列的来源只有一处：`workbook.parse_composition()` 解析首表「树种组成」→ 存 `subcompartments.species_json`；
  `app.sub_detail()` / `clean_survey()` / 导出都用这份 JSON，前后端没有第二套口径。
- 样地表（真实工作簿）里带材积公式的树种正好是 4 个：云南松、油杉、其他阔叶、栎类（`tests/test_app` 已有断言）——
  即「固定 4 种」不会缺公式，不需要新造参数。
- 调查页树种 chip 目前拼的是 `${coefficient}${name}`，固定树种没有系数，会渲染成 `null云南松`，必须一起改。

## 3. 设计方案（逻辑 + 口径依据）

1. **新参数 key `调查树种`**（类型「树种」，默认空）：
   - **留空 = 维持 v1.0 行为**（按树种组成拆分），满足 C15「无参数表时行为等于默认」；
   - 非空 = 调查页固定这几个树种，**与树种组成无关**，每个小班都一样。
2. **分隔符按外业习惯放宽**：空格 / 顿号 / 逗号 / 分号 / 斜杠 / 竖线都认，`云南松  油杉  其他阔叶  栎类` 直接可用。
   其余列表型 key 仍只认半角分号（`_split`），不把宽松口径扩散到全表。
3. **不自动纠错**（C13）：参数里的树种名必须在样地表里有材积公式，否则带 Excel 行号报错并列出可用树种；
   重复树种同样报错。绝不把「桦木」猜成「其他阔叶」。
4. **组成原文不动**：`fields.composition` 照旧保留，列表/导出里的「树种组成」仍可追溯原始组成；
   固定的只是「调查页显示哪几列」。这样参数写错了改参数重传即可，数据侧没有不可逆改动。
5. **三处口径同源**：详情（列）、保存校验（允许的树种）、导出（明细的树种列）统一走 `workbook.survey_species()`，
   避免「页面能填、保存被拒」或「导出少树种类」。
6. **界面不露技术写法**：固定树种没有组成系数，chip 只显示树种名（`云南松`），不再出现 `9云南松`。

## 4. 代码修改（文件 + 要点）

- `param_parser.py`：`KEYS` 增 `调查树种`（类型 `树种`，默认空）；新增 `SPECIES_SPLIT` 与 `_species_items()`
  （宽容分隔符、去重、按 `species_choices` 校验）；`parse_program_params(..., species_choices=None)`；
  `default_params()` 对「树种」型返回 `[]`。
- `workbook.py`：`parse_program_params` 传入 `species_choices=list(schema["species"])`；
  新增 `survey_species(record_species, params)` —— 参数非空则返回 `[{name, coefficient: None}]`，否则原样返回组成拆分。
- `app.py`：`sub_detail` / `plot_payload` / `clean_survey` / 导出 `project_export` 全部改走 `survey_species`；
  保存校验文案改为「不在本小班调查树种里」；`ASSET_VERSION` → `v1.6`。
- `static/app.js`：`#speciesChips` 渲染 `coefficient == null ? '' : 系数`。
- `data/程序参数模板.xlsx`：在「不显示列」后追加 `调查树种` 一行（11 个 key）。
- 文档：本文件、`README.md` 参数表、`STATE.md`、`CONSTRAINTS.md`（C21）。

## 5. 测试验证

新增 4 条断言（`tests/test_app.py`）：

| 用例 | 断言 |
|---|---|
| `test_param_sheet_fixed_survey_species_skips_composition` | 空格写法解析成 4 种；组成原文仍解析为「云南松、其他阔叶」；`survey_species` 返回 4 种且 `coefficient` 为 None |
| `test_fixed_survey_species_accepts_plain_separators` | 顿号/中英文逗号/分号/斜杠/竖线混用 → 同一结果 |
| `test_fixed_survey_species_rejects_unknown_and_duplicate` | 「桦木」报「样地表现有树种」；重复报「树种重复」；均带「第2行」 |

`python3 -m unittest tests.test_app` → **42 项全通过**（原 38 + 新增 4）。
